# Rev A generated exports

These STL and 3MF files were generated from `../../kveld_enclosure.scad` with OpenSCAD 2026.06.12. They are convenience files for fit prototypes. The SCAD source remains authoritative.

The directory contains the shell, base, retainer, caps, lens surrogate, steel skin, light pipe, and four fit coupons. The button coupon is the gauge plate; print the two cap files separately and insert them for the fit check. The lens and steel files are three-dimensional fit references; a fabricator still needs a reviewed drawing, material, finish, edge and tolerance specification.

Do not scale an export in the slicer. Regenerate every affected export after a source change and run `just hw-case-check` before committing it.
