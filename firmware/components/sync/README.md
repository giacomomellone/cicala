# sync

HTTPS manifest check, per-language bundle download, sha256 + ed25519 signature verification, and atomic swap in LittleFS — the full flow is specified in [docs/SYNC-PROTOCOL.md](../../../docs/SYNC-PROTOCOL.md). Runs only on charger + known Wi-Fi (or manual "sync now"); any failure keeps the old bundle.

`trusted_key.h` (the embedded ed25519 **public** key) is generated by `tools/keygen.py` and committed here once the real signing keypair exists; the private key lives only in the `BUNDLE_SIGNING_KEY` GitHub Actions secret. Release firmware must reject unsigned (`"sig": null`) manifests.
